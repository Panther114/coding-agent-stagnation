# Coding-agent stagnation study

Does an online monitor detect that a coding agent has stalled — and what can a runtime
legitimately do about it?

**S.-T. Yau High School Science Award (Computer Science), 2026.** Ziheng Yu and Xuhao Chen.
An autonomous AI agent did the implementation, annotation logistics and drafting; every
contribution, defect and retraction is logged in `research/AI_ASSISTANCE_LOG.md`.

The research package, its findings and the five verification gates live in `research/` — start
at `research/README.md`. The report is in `essay/` (source `essay/main.tex`).

Live-agent batteries run on real packages in isolated arm dirs (`tasks/src-*/`, never
committed). The codextras taskbed is https://github.com/willuhd/codextras (private).
