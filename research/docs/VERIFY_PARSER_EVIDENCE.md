# Per-step verification parser: evidence from the real corpus

Generated by `scripts/make_verify_evidence.py`; every string below is a literal
substring captured from `data/raw/nebius/train-*.parquet`.

- **Corpus read:** `data/raw/nebius/train-*.parquet` (raw SWE-agent trajectories).
  `data/processed/steps_full/nebius/` was empty while this ran, so it was not used;
  `data/processed/steps/nebius/` has derived features only and carries no observation text.
- **Scan:** 4,000 runs, 102,617 observations.
- Regexes in `src/agentstall/verify.py` were written from these strings, not from
  recollection of what pytest/unittest "should" print.

## 1. Patterns driving the parser

| what it is | observations matched | drives |
|---|---:|---|
| pytest session header | 427 | context only: proves the observation is a pytest run |
| pytest terminal summary | 426 | `_read_pytest` -> n_tests_passed/failed/errored, EXIT_* signal |
| collected N items | 427 | `_read_collected` -> n_collected |
| collected N items / M errors | 29 | `_read_collected` -> n_collected + has_collection_errors |
| Interrupted during collection | 29 | `_read_errors_only` -> EXIT_COLLECTION_ERROR |
| pytest short summary info | 209 | marks the block that carries `FAILED <nodeid>` lines |
| pytest FAILED node id | 347 | `extract_failure_ids` -> failure_ids / new_failure_ids |
| pytest ERROR line (module level) | 33 | `_read_errors_only` -> EXIT_ERROR |
| truncated FAILED message | 118 | audit: the node id survives, the message does not |
| unittest Run summary | 303 | `_read_unittest` -> n_collected |
| unittest OK verdict | 130 | `_read_unittest` -> EXIT_ALL_PASS |
| unittest FAILED verdict | 173 | `_read_unittest` -> n_tests_failed / n_tests_errored |
| unittest FAIL/ERROR banner | 173 | `extract_failure_ids` -> unittest node ids, canonicalised |
| nose2 loader failure | 95 | `_read_errors_only` -> EXIT_ERROR (a whole module failed to load) |
| no tests ran | 6 | `_read_pytest` -> EXIT_NO_TESTS |
| progress but no verdict | 392 | `_read_progress` -> has_progress; keeps EXIT_UNKNOWN honest |
| timeout / kill | 2,488 | audit only: a killed suite yields no verdict |

## 2. Tricky cases the parser must survive

| case | observations matched | why it matters |
|---|---:|---|
| parametrised node ids | 9 | `[add_repeated]`, `[1-2-X]` and `[with spaces-in id]` must stay attached to the id |
| warnings interleaved with results | 131 | `4 warnings` must never be counted as failures or as passes |
| deselected tests | 7 | `54 deselected` is not 54 tests |
| truncated output | 392 | progress is visible but no summary follows, so the step must stay `unknown`; `truncated` is exactly `progress and not _verdict_present` |
| elided failure message | 57 | pytest's own truncation, not the harness's: the node id survives intact |
| no tests collected | 24 | must be `no_tests`, distinct from a pass |
