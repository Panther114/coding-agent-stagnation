# VERSIONS — documentation map

Prose lives in top-level `docs/`, prefixed by research iteration. `research/docs/`
retains only generated/working files (annotation cards are data under `datasets/`;
`human_check_sample.md` / `human_check_readable.md` are script outputs;
`lit_raw/`, `verify_raw/`, `_raw/`, `award/` are evidence caches).

- **0-*** — competition brief and submission mechanics (`0-brief.md` = the original
  `main_idea.md` research brief; `0-submission-checklist.md`).
- **1-*** — v1 judged-label study: codebook + findings on AI-reader labels
  (`1-annotation-guide.md`, `1-key-findings.md`).
- **2-*** — rebuild on mechanical labels: gap analysis, frozen plan, findings v1/v2,
  corpus + literature recon, parser evidence, handoff, executive summary.
- **3-*** — this session: blind human pilot (packet lives at
  `research/docs/human_check_blind/` — kept whole because the sealed key references it;
  sheet/prereg/provenance/results here), audit, misfire matrix, cost anatomy.
- **4-*** — reserved for future docs; draft unprefixed, version on freeze.

Within-doc historical paths (e.g. `research/docs/...` named inside 1-*/2-* texts) refer to
locations at time of writing; this map is the translator. Do not rewrite history in place.
